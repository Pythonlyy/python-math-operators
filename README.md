# ➕ Do Math Like a Calculator in Python

Python can do all kinds of math — just like a calculator!
You can use it to add, subtract, multiply, divide, and more.

---

## 💡 Common Math Operators

| Operator | Meaning            | Example  | Result |
| -------- | ------------------ | -------- | ------ |
| `+`      | Addition           | `2 + 3`  | `5`    |
| `-`      | Subtraction        | `5 - 2`  | `3`    |
| `*`      | Multiplication     | `4 * 2`  | `8`    |
| `/`      | Division           | `10 / 2` | `5.0`  |
| `**`     | Power (Exponent)   | `3 ** 2` | `9`    |
| `%`      | Modulo (Remainder) | `10 % 3` | `1`    |

---

## 💻 Example with Explanation

```python
print(2 + 3)     # 5
print(5 - 1)     # 4
print(3 * 2)     # 6
print(8 / 2)     # 4.0
print(2 ** 3)    # 8
print(10 % 4)    # 2
```

### 🔈 Output

```
5
4
6
4.0
8
2
```

---

### 📌 Key Notes

* Division `/` always gives a **float** (e.g., `4.0`)
* `**` is used for powers (like 2 to the 3rd power)
* `%` gives you the **remainder** of a division

---

## 🧪 Try It Yourself

```python
print("Addition:", 7 + 3)
print("Subtraction:", 10 - 4)
print("Multiplication:", 6 * 6)
print("Division:", 9 / 2)
print("Exponent:", 2 ** 4)
print("Remainder:", 11 % 5)
```
